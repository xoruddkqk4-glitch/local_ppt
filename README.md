# Local ppt

Local ppt는 별도의 빌드나 서버 설치 없이 로컬의 `index.html`을 브라우저에서 열어 사용하는 프레젠테이션 편집기입니다. 왼쪽 패널에서 디자인과 본문 구조를 선택하고, 오른쪽 16:9 캔버스에서 PowerPoint처럼 개체를 직접 편집할 수 있습니다.

서버나 계정 없이 프레젠테이션을 만들고, 전체 작업 내용을 사람이 읽을 수 있는 JSON 기반 `.txt` 파일로 보관하는 것이 이 프로젝트의 목표입니다. 페이지의 내용과 이미지까지 하나의 파일에 저장되므로 다른 컴퓨터에서도 같은 프로젝트를 이어서 편집할 수 있습니다.

## 편집기 구성

- **PAGE 01 — 표지:** 프레젠테이션 제목과 부제목을 편집하고, 필요하면 계층형 텍스트 항목을 추가하며 전체 디자인을 결정합니다.
- **PAGE 02 이후 — 본문:** 개조식, 마인드맵 또는 개체형 템플릿으로 내용을 구성합니다.
- **왼쪽 패널:** 디자인·템플릿 선택, 항목 추가·삭제, 이미지 삽입을 담당합니다.
- **오른쪽 캔버스:** 텍스트 직접 편집, 개체 선택·이동·크기 조절과 전체 화면 미리보기를 제공합니다.

## 디자인

하나의 프레젠테이션에는 하나의 디자인이 적용되며 PAGE 01에서만 변경할 수 있습니다.

| 디자인 | 특징 | 기본 강조색 |
|---|---|---|
| Bauhaus | 기하학, 삼원색, 강한 타이포그래피와 기능적인 그리드 | 파스텔 레드 |
| Claymorphism | 부드러운 파스텔 색상, 둥근 모서리와 입체적인 그림자 | 파스텔 핑크 |
| Neo-Brutalism | 굵은 검은 테두리, 고대비 원색과 단단한 그림자 | 고대비 레드 |
| Skeuomorphism | 실제 재질을 연상시키는 질감과 입체적인 UI | 코럴 레드 |
| Swiss Minimal | 넉넉한 여백, 엄격한 그리드와 절제된 색상의 미니멀 디자인 | 스위스 블루 |
| Swiss Grid Modern | 12열 그리드, 고대비 흑백과 데이터 중심의 정밀한 구성 | 시스템 블루 |
| Functional Bauhaus | 기능적인 비대칭 구성과 절제된 삼원색의 강한 타이포그래피 | 바우하우스 레드 |
| Soft Layered Minimal | 밝은 중성 배경, 낮은 채도와 부드러운 카드 깊이감 | 소프트 인디고 |
| Controlled Neo-Brutalism | 정돈된 굵은 테두리, 제한된 원색과 작은 오프셋 그림자 | 코럴 레드 |
| Tactile Product Minimal | 제품 UI를 닮은 정밀한 컨트롤과 금속성 중성색 | 인더스트리얼 블루 |

타임라인의 곡선·화살표와 `카드형 그리드(측면 강조)`의 세로선은 해당 디자인의 개조식 항목에 적용되는 강조색을 자동으로 공유합니다.

## 레이아웃과 다이어그램

개체형 템플릿을 선택하면 레이아웃과 다이어그램 모두 접이식 썸네일 목록에서 구조를 미리 보고 선택할 수 있습니다.

|---|---|

| 측면 강조 카드 1×3 | 세로 컬러 라인과 굵은 제목·설명으로 구성된 3열 카드 배치 |
| 테이블 | 헤더와 데이터 행으로 구성되며 행과 열을 독립적으로 추가·삭제할 수 있는 표 |
| 비교 패널 1×2 | 두 개념이나 전후 상태를 나란히 비교 |

| 메인 테이블 + 우측 지표 3×1 | 넓은 테이블 오른쪽에 세로 지표 카드를 배치 |

측면 강조 카드는 기본 3열로 생성되며 항목이 늘어나면 다음 행으로 자동 배치됩니다. 타임라인은 기본 5단계로 생성되고 각 구간의 제목과 설명을 두 줄로 직접 편집할 수 있습니다. 사분면은 4개, VS는 2개로 고정되며 나머지 다이어그램은 구조별 허용 범위 안에서 항목을 추가·삭제할 수 있습니다.

## 실행 방법

### 가장 간단한 방법

1. 저장소를 내려받거나 복제합니다.
2. 프로젝트 폴더의 `index.html`을 Chrome 또는 Edge에서 엽니다.

```bash
git clone https://github.com/xoruddkqk4-glitch/local_ppt.git
cd local_ppt
```

### 로컬 서버로 실행

브라우저의 로컬 파일 보안 정책 때문에 일부 파일 기능이 제한되면 간단한 로컬 서버를 사용할 수 있습니다.

```bash
python -m http.server 8765
```

그다음 브라우저에서 `http://127.0.0.1:8765`를 엽니다.

별도의 패키지 설치나 빌드 과정은 없습니다. Pretendard 웹폰트는 jsDelivr CDN에서 불러오므로 완전한 오프라인 환경에서는 시스템 기본 글꼴로 대체될 수 있습니다.

## 기본 사용 흐름

1. PAGE 01에서 프레젠테이션 전체 디자인을 선택합니다.
2. `+ 본문 페이지`를 눌러 PAGE 02 이후의 본문 페이지를 만듭니다.
3. 본문 템플릿을 선택합니다.
4. 개체형이라면 레이아웃 또는 다이어그램을 선택합니다.
5. 캔버스의 텍스트를 더블클릭해 내용을 수정합니다.
6. 개체를 드래그하거나 우하단 핸들로 크기를 조절합니다.
7. `전체 화면` 버튼 또는 `F` 키로 현재 페이지를 전체 화면에서 확인합니다.

## 캔버스 조작

| 동작 | 조작 방법 |
|---|---|
| 텍스트 편집 | 텍스트 개체 더블클릭 |
| 개체 이동 | 개체 드래그 |
| 개체 크기 조절 | 개체 우하단 핸들 드래그 |
| 복수 선택 | `Ctrl`/`Cmd` + 개체 클릭 |
| 복수 개체 이동 | 복수 선택 후 선택된 개체 드래그 |
| 개체 복사·붙여넣기 | 개체 선택 후 `Ctrl+C`/`Cmd+C`, `Ctrl+V`/`Cmd+V` |
| 페이지 복사·붙여넣기 | 개체를 선택하지 않은 상태에서 본문 페이지를 선택한 뒤 `Ctrl+C`/`Cmd+C`, `Ctrl+V`/`Cmd+V` |
| 선택 해제 | `Esc` |
| 개조식·표지 항목 하위 위계 | 항목 선택 후 `Tab` |
| 개조식·표지 항목 상위 위계 | 항목 선택 후 `Shift+Tab` |
| 되돌리기 | `Ctrl+Z`/`Cmd+Z` |
| 전체 화면 | `F` 또는 상단 `전체 화면` 버튼 |

이동과 크기 조절 중에는 5% 격자와 다른 개체의 가장자리 및 중앙선에 자동으로 맞춰집니다. 스냅되는 위치는 빨간 점선 가이드로 표시됩니다.

페이지를 복사하면 텍스트, 이미지, 개체 위치와 크기, 마인드맵 연결을 포함한 페이지 전체가 복제됩니다. 붙여넣은 페이지는 현재 페이지 바로 뒤에 삽입되며 자동으로 선택됩니다. PAGE 01은 프레젠테이션의 고정 표지이므로 페이지 복사 대상에서 제외됩니다.

## 항목 추가 및 삭제

표지에서는 선택 없이 새 텍스트 항목을 추가할 수 있습니다. 본문에서는 항목 개체를 하나 선택해야 왼쪽 패널의 `+ 항목`과 `− 항목` 버튼이 활성화됩니다. 테이블 레이아웃에서는 표를 별도로 선택하지 않아도 행·열 관리 기능을 사용할 수 있습니다.

- 표지: 도형 없는 텍스트 항목을 추가합니다. 항목을 선택한 뒤 `Tab` 또는 `Shift+Tab`으로 위계를 조정할 수 있습니다.
- 개조식: 선택한 항목 다음에 새 항목을 추가하거나 선택한 항목을 삭제합니다. `Tab`은 하위 위계, `Shift+Tab`은 상위 위계로 변경하며 위계가 내려갈수록 글자 크기가 작아집니다.
- 마인드맵: 선택한 노드에 하위 가지를 추가합니다. 4단계에서는 더 깊은 가지를 추가할 수 없습니다. 가지를 삭제하면 그 아래의 모든 하위 가지도 함께 삭제됩니다. 추가와 삭제는 나머지 노드의 위치에 영향을 주지 않습니다.
- 테이블: 테이블 레이아웃에서만 표시되는 `테이블 관리 대상`에서 행 또는 열을 선택한 뒤 해당 방향으로 추가·삭제합니다.
- 레이아웃 및 다이어그램: 선택 상태를 기준으로 항목 수를 조정합니다.

## 프로젝트 저장 파일

상단의 세 버튼으로 프로젝트를 관리할 수 있습니다.

- `불러오기`: Local ppt `.txt` 또는 `.json` 프로젝트 열기
- `현재 txt에 저장`: 현재 연결된 파일에 저장
- `다른 이름으로 저장`: 새로운 `.txt` 파일로 저장

저장 파일은 사람이 읽을 수 있도록 들여쓰기된 JSON이며 다음 정보를 포함합니다.

- 선택한 디자인
- 모든 페이지와 템플릿 정보
- 개체의 위치와 크기
- 텍스트 내용과 서식
- 마인드맵 계층 관계
- Base64 형식으로 포함된 이미지

Chrome과 Edge에서 File System Access API를 사용할 수 있으면 불러오기와 다른 이름으로 저장이 동일한 Local ppt 전용 최근 폴더를 기억합니다. API를 사용할 수 없는 브라우저에서는 파일 입력 및 다운로드 방식으로 대체됩니다.

> 저장 파일에는 이미지 데이터도 포함되므로 이미지를 많이 삽입하면 `.txt` 파일 크기가 커질 수 있습니다.

## 프로젝트 구조

```text
local_ppt/
├─ index.html             # 편집기 화면과 도구막대
├─ app.js                 # 페이지 모델, 캔버스 편집, 저장·불러오기
├─ style.css              # 편집기 및 디자인 스타일
├─ templates/
│  └─ schema.js           # 본문 템플릿 정의
├─ designs/
│  └─ options.js          # 디자인 선택지
├─ layouts/
│  └─ options.js          # 개체형 레이아웃 정의
└─ diagrams/
   └─ options.js          # 개체형 다이어그램 정의
```

각 기능군을 별도 폴더로 분리해 새로운 디자인, 템플릿, 레이아웃 또는 다이어그램을 추가할 때 편집기 핵심 로직과 정의 파일이 뒤섞이지 않도록 구성했습니다.

## 브라우저 지원

최신 Chrome 또는 Edge 사용을 권장합니다. 두 브라우저에서는 File System Access API를 이용해 현재 파일에 바로 저장하고, `불러오기`와 `다른 이름으로 저장`에서 최근에 사용한 폴더를 공유할 수 있습니다.

Firefox와 Safari에서도 기본 편집 및 다운로드 방식의 저장을 사용할 수 있지만, 브라우저 정책에 따라 현재 파일 덮어쓰기와 최근 폴더 기억 기능은 제한될 수 있습니다.

## 데이터와 개인정보

편집 내용은 외부 서버로 전송되지 않습니다. 프로젝트 데이터는 브라우저 메모리와 사용자가 선택한 로컬 `.txt` 파일에서만 처리됩니다. Pretendard 웹폰트만 jsDelivr CDN에서 불러오며, 오프라인에서는 시스템 기본 글꼴로 대체될 수 있습니다.

## 기술 구성

- HTML5
- CSS3
- Vanilla JavaScript
- Fullscreen API
- File System Access API 및 파일 다운로드 폴백
- FileReader 기반 다중 이미지 삽입

프레임워크와 런타임 의존성이 없기 때문에 파일을 복사하는 것만으로 프로젝트를 배포하거나 보관할 수 있습니다.
